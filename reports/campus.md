# 后端与 AI 方向岗位技能需求分析报告

## 样本局限性

本次分析基于 285 个成功抽取的岗位，来源为字节跳动、腾讯、小红书、蔚来、百度、小鹏汽车、网易、大疆、滴滴共 9 家公司，筛选方向为 backend 和 ai。原始库内有 10014 个岗位，实际分析仅占 2.8%。样本严重偏向字节跳动（库内 6507 条），且 9 家均为大型互联网或智能硬件公司，不代表中小企业、外企或传统行业。职级分布中初级岗占 150/285（含大量实习和校招），结论更适用于 0-3 年经验的求职者，对资深岗位的判断力度有限。该样本能反映头部科技公司当前招聘的技能偏好趋势，不能支撑薪资、地域差异或全行业供需比的结论。

## 核心市场信号

**AI 方向彻底压过纯后端。** 分方向数据中，算法/AI/大模型子方向的技能频次远高于后端/服务端（Python 122 vs 18，LLM 125 vs 4）。高频领域前三为自动驾驶（25/285）、多模态大模型（24/285）、具身智能（20/285），均为 AI 密集领域。纯后端开发仅作为领域出现 7 次。

**LLM 已成为基础要求。** LLM 出现在 129/285 个岗位，仅次于 Python（140/285）。与之配套的 RAG（29）、AI Agent（33+23=56 合并计算）、RLHF（13）、SFT（14）形成完整的大模型应用与对齐技术栈。

**职级偏初级但门槛不低。** 实习和校招相关标签累计出现超过 50 次，但同时「顶会论文优先」出现 14 次、「顶会一作论文加分」7 次、「ACM 竞赛获奖优先」8 次，说明即使是入门岗位，学术产出和竞赛背景仍有显著加分。

## 高频但供给通常不足的技能

以下技能在数据中频次显著，但根据行业通常的人才储备情况，供需缺口较大：

- **强化学习（49/285）：** 市场上具备 RL 工程落地能力的人远少于具备监督学习经验的人，多数开发者停留在理论了解层面。RLHF（13）和 SFT（14）的出现进一步确认对齐训练人才稀缺。
- **AI Agent 工程化（33+23=56）：** Agent 概念热度高，但具备多步规划、工具调用、记忆管理等工程实现经验的人有限，多数项目仍处于 demo 阶段。
- **CUDA 与分布式训练（CUDA 22，分布式训练 19）：** 需要同时理解 GPU 架构和训练框架内部机制，学习曲线陡峭，科班训练中覆盖不足。
- **模型量化（15/285）：** 部署侧刚需，但专门做量化工程的人才池极小。
- **具身智能/VLA（领域 20，技能 VLA 14）：** 交叉机器人学和视觉语言模型，属于新兴方向，人才储备几乎从零开始。

数据不足，无法判断上述技能的实际薪资溢价幅度。

## 学习路径

以下路径面向有一定编程基础、想转向或深入 AI 工程方向的开发者。

### 立刻补（1 个月内）

| 学什么 | 数据信号 | 够用标准 |
|--------|----------|----------|
| Python 工程能力 | 140/285 岗位要求 | 能独立写生产级代码，熟悉 async、typing、包管理 |
| LLM API 调用与 Prompt Engineering | LLM 129/285 | 能用 OpenAI/Claude API 完成结构化输出、few-shot、function calling |
| RAG 基础实现 | RAG 29/285 | 能搭建向量检索 + LLM 生成的完整管线，理解 chunking 策略和 embedding 选型 |
| Linux 基本操作 | Linux 40/285 | 能在服务器上部署服务、排查进程和日志 |

### 3-6 个月

| 学什么 | 数据信号 | 够用标准 |
|--------|----------|----------|
| PyTorch 模型训练 | PyTorch 78/285 | 能从零实现 fine-tune 流程，理解 DataLoader、混合精度、梯度累积 |
| AI Agent 架构 | AI Agent 56/285（合并） | 能实现多步 tool-use Agent，处理状态管理、错误恢复、上下文窗口限制 |
| 强化学习基础 + RLHF/SFT | 强化学习 49，RLHF 13，SFT 14 | 能理解 PPO/DPO 原理，能跑通一个对齐训练实验 |
| C++ 系统编程 | C++ 84/285 | 能读写中等复杂度 C++ 代码，理解内存管理和多线程（尤其面向推理引擎或自动驾驶方向） |
| Transformer 架构深入 | Transformer 16/285 | 能手写 attention 机制，理解 KV-cache、RoPE 等推理优化 |

### 长期（6 个月以上）

| 学什么 | 数据信号 | 够用标准 |
|--------|----------|----------|
| CUDA 与 GPU 编程 | CUDA 22/285，分布式训练 19 | 能写自定义 CUDA kernel，理解 memory hierarchy，能做算子级优化 |
| 模型量化与部署 | 模型量化 15/285 | 掌握 GPTQ/AWQ/GGUF 等方案，能在延迟和精度间做工程权衡 |

| 具身智能/VLA | 具身智能领域 20，VLA 14 | 能将视觉语言模型接入机器人控制回路，理解 sim-to-real 迁移（该方向极新，学习资源有限） |
| 分布式系统设计 | 分布式系统 13，Kubernetes 13 | 能设计高可用服务架构，理解训练集群调度 |

## 补充说明

纯后端方向（Java 17、Golang 11、MySQL 7、Redis 4）在本样本中需求量明显低于 AI 方向，但这受限于本次筛选条件包含了 ai 标签。纯后端的真实市场体量数据不足，无法判断其绝对需求是否下降。对于已有后端经验的开发者，将 LLM 集成能力和 Agent 工程化作为叠加技能是数据支持最明确的路径——后端子方向中 LLM 仍出现 4 次，分布式系统 7 次，说明后端岗位也在向 AI 基础设施靠拢。
