# AI/后端方向岗位技能需求分析报告

## 样本局限性说明

本次分析基于 20 个岗位，从字节跳动、小红书、小鹏汽车、百度、网易、蔚来 6 家公司的库内 9134 个岗位中筛选，方向限定为 backend 和 ai。样本量极小（仅占库内 0.2%），且职级分布严重偏向初级（19/20 为初级，仅 1 个中级）。信号中"校招2027届"出现 7 次、"本科及以上在读"出现 7 次，说明样本以实习和校招为主。

这个样本能支撑的结论：当前头部互联网和新能源车企对 AI 方向初级人才的技能偏好趋势。不能支撑的结论：中高级岗位需求、薪资预期、行业全貌、非头部公司的需求差异。

## 核心技能需求格局

LLM 出现在 15/20 个岗位，是压倒性的第一需求。Python（10/20）为基础语言。第二梯队为机器学习（7/20）、PyTorch（6/20）、多模态（6/20）、AI Agent（6/20）。第三梯队为 C++（5/20）、强化学习（5/20）、RAG（4/20）、Golang（4/20）、深度学习（4/20）。

后端方向岗位仅 1-2 个，技能点分散（Golang、MySQL、Redis、消息队列、高并发各出现 1 次），数据不足，无法判断后端方向的系统性需求。

领域分布上，数据工程（5/20）最高，其次是多模态（3/20）、云计算/AI平台（2/20）、具身智能（2/20）。

## 高频但供给通常不足的技能

以下技能频次较高，但根据行业一般供给情况，属于人才缺口明显的方向：

- RLHF（3/20）+ DPO（2/20）+ SFT（3/20）：对齐技术栈合计覆盖约 8 个岗位提及。这类技能需要实际训练经验，课程和教材覆盖滞后，多数候选人停留在论文阅读层面。
- 数据合成 / 合成数据（3+2=5 次提及）：大模型数据工程是新兴工种，传统数据工程师不具备此技能，AI研究者又往往不做工程化。
- AI Agent（6/20）+ RAG（4/20）：应用落地经验要求高，但多数人仅有 demo 级项目，缺少生产环境的工程闭环经验。
- 多模态 / VLM（6+2=8 次提及）：多模态人才培养周期长，需要同时理解视觉和语言模型，供给显著少于纯 NLP 方向。
- 模型评测（2/20）：信号中"强调评测闭环与效果归因"单独出现，说明企业已将评测视为独立能力而非附属工作，但市场上系统掌握评测方法论的人很少。

## 学习路径

### 立刻补（1 个月内）

- Python 工程能力：10/20 岗位要求，且是几乎所有 AI 岗的前置条件。达标标准：能独立写出可维护的数据处理 pipeline，熟练使用 HuggingFace Transformers 库加载和调用模型。
- LLM 基础认知：15/20 岗位提及。达标标准：理解 Transformer 架构（2/20 单独提及 Transformers）、Prompt Engineering 基本范式、主流模型的能力边界，能使用 API 完成端到端任务。
- PyTorch 基本功：6/20 岗位要求。达标标准：能独立搭建训练循环、读懂开源模型代码、做简单的 fine-tuning。

### 3-6 个月

- RAG + AI Agent 工程实践：RAG 4/20、AI Agent 6/20。目标：从 demo 走向生产级系统，掌握检索策略优化、Agent 工具编排、Function Call（后端方向明确提到）、多轮对话管理。输出一个可展示的完整项目（信号中"要求可展示的开源/竞赛/项目成果"出现 1 次）。
- RLHF / DPO / SFT 对齐技术：合计 8 次提及。目标：至少完成一次从数据标注到 SFT 再到 RLHF/DPO 的完整流程，理解奖励模型训练和偏好优化原理。
- 数据合成能力：3/20 提及数据合成，2/20 提及合成数据。目标：掌握用 LLM 生成训练数据的方法论，包括质量过滤、多样性控制、数据去污染。

### 长期（6 个月以上）

- 多模态 / VLM：6/20 提及多模态，2/20 提及 VLM。需要在视觉编码器、跨模态对齐、多模态指令微调等方面积累深度。目标：能独立完成多模态模型的训练或适配工作。
- 强化学习：5/20 岗位要求。结合具身智能（2/20）方向来看，RL 在机器人和游戏 AI 场景有持续需求。目标：掌握 PPO 等主流算法的工程实现。
- 顶会论文能力："顶会论文优先"出现 5/20 次，这是长期竞争力的核心区分度。目标：在 NeurIPS/ICLR/ACL/CVPR 等会议发表工作。

## 补充观察

职级几乎全为初级（19/20），结合校招和实习信号来看，当前这批岗位的竞争维度不是工作年限，而是项目深度和研究产出。"顶会论文优先"5/20、"要求独立AI项目/竞赛/论文/开源"1/20、"CTF参赛/开源项目/技术博客加分"1/20，说明可验证的产出是关键筛选条件。

传统后端技能（Java 2/20、分布式系统 2/20、MySQL/Redis 各 1/20）在本样本中频次低，但这可能是样本偏向 AI 方向的结果，数据不足，无法判断后端基本功的真实市场权重。
